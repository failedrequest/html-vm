Migrate VM

Transfer a VM to another host using vm migrate. Requires ZFS and SSH key-based auth to the destination host. The VM will be stopped briefly at the end of the transfer for the final incremental snapshot.

Migration can take many minutes for large VMs. The UI will block until it completes. SSH key-based auth must be configured between this host and the destination — password prompts will cause the migration to hang.

How it works

  1. Takes a full ZFS snapshot and streams it to the remote host.
  2. If triple mode: takes an incremental snapshot and streams it.
  3. Powers off the VM and sends a final incremental snapshot.
  4. Remote host has a running copy of the VM dataset.
  5. If "Start remote" is checked, starts the VM on the remote host.
  6. If "Destroy local" is checked, removes the VM from this host.
